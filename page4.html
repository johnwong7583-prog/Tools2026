1. 零估算原則（嚴格核實）：系統全面停用任何價格推算演算法。凡未經官網商品頁實測確認現貨之型號，一律標示『—』（不代表該店必然缺貨，僅代表未納入本次自動比對），避免出現虛假低價誤判。

2. 豐澤（Fortress）四層價格過濾規則：豐澤商品頁常並列多種價格，本系統僅採納「一般網店售價／快閃優惠價」（例如 Philips 27M2N6500L 實測網店價為 HK$3,640），並自動排除：① 劃線「建議價 (RRP)」；② 需於購物車選用之「恒生／滙豐信用卡限定價」；③ 標示「缺貨」之商品；④ Mesh 路由器單件裝「HK$ X 起」混入多件裝比對。

3. CPU 包裝與付款條件：CPU 按完整型號與 BOX 盒裝／TRAY 散裝 分開比較，包裝不明者省略。中田「轉數快優惠」價亦納入最低價及價差計算，限砌機、跟板及加購優惠不計。

4. 其餘腦場網站現貨過濾：Jumbo 部分結構資料雖標 InStock，主商品頁明示『訂貨／最快一天到貨』者一律排除；SE 按新版官網核對主商品現貨及唯一變體售價；法奧及未來科技僅列明示現貨項目。
