GitHub Pages 404 Error 診斷與一鍵修復工具

為什麼 GitHub Pages 會出現 404 File not found？

1. 主檔名不是 index.html（95% 原因）：GitHub Pages 預設只會尋找小寫的 index.html 作為首頁。若上載檔名為 pc_generator_pro.html，直接打開網址就會出現 404！
2. 缺少 .nojekyll 與 404.html：開啟 GitHub Pages 時若未關閉 Jekyll 編譯或打錯子路徑，亦會觸發 404。

GitHub Pages 正確設定 3 步驟（確認無誤後 1 分鐘內生效）：
  1. 將上方下載的 index.html（或解壓縮 ZIP 內的全部檔案）上傳到您的 GitHub Repository 最外層根目錄 (Root)。
  2. 進入 GitHub 專案頂部的 Settings (設定) ➔ 左側選單點擊 Pages。
  3. 在 Build and deployment (Source) 選擇 Deploy from a branch，Branch 選擇 main（或 master）以及資料夾 / (root)，再按 Save 即可！
